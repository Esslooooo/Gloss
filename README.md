# Gloss

一个 Chrome 扩展。双击网页上的英文单词，弹出中文释义，自动记录到生词本，支持划选句子翻译和按 SM-2 算法复习。

## 安装
Gloss 不在 Chrome 应用商店，需要手动加载。整个过程 1 分钟。

### 准备工作
Chrome 浏览器（任意较新版本），Edge、Brave、Arc 等 Chromium 内核的浏览器同样可用。

### 第一步：下载代码

**方式 A（推荐）**：在 GitHub 页面点右上角绿色的 `<> Code` 按钮 → 选 `Download ZIP`，会下载一个 `gloss-main.zip`。

**方式 B**：如果已装 git，可用命令行：
```
    git clone https://github.com/Esslooooo/gloss.git
```

### 第二步：解压
将 ZIP 解压到一可长期保留的位置，比如 `~/Documents/Gloss` 或`D:/Gloss`。
注意：解压后的文件夹不可删除或移动。
解压后的文件夹里应可直接看到以下文件：
```
    gloss/
    ├── manifest.json
    ├── background.js
    ├── content.js
    ├── popup.html
    ├── ...
    └── dict-parts/
```
**检查**：打开文件夹，第一眼应该能看到 `manifest.json`。如果看到 `gloss-main` 文件夹，再点进去才是如上文件，说明有一层目录多余，Chrome 加载时会出错。

### 第三步：加载到 Chrome
1. 打开 Chrome，地址栏输入 
```chrome://extensions/```，回车
2. 打开右上角的「开发者模式」开关
3. 选择「加载已解压的扩展程序」
4. 在弹出的文件选择窗口里，选中第二步解压出来的文件夹
5. 加载成功。扩展卡片会出现在页面上，名称显示为 **Gloss**

### 第四步：固定到工具栏

默认情况下，Chrome 会把新扩展藏在「拼图」菜单里。

1. 点击浏览器工具栏上的拼图图标（在地址栏右侧）
2. 找到 **Gloss**
3. 点右边的图钉图标，将它固定到工具栏

### 安装完成后
Chrome 可能会提示「请停用以开发者模式运行的扩展程序」。这是 Chrome 对未上架应用商店的扩展的标准提示，忽略即可，不影响使用。

## 首次使用

### 第一步：下载本地词典
打开 Gloss（点工具栏图标）→ 点右上角 ⚙️ → 找到「本地词典」区域 → 点「下载本地词典」。
会从 CDN 下载约 100 万词条，需要 1~3 分钟。
下载完成后：状态显示为「已安装 · XXXXXXX 词条」，之后可以离线查词。

### 第二步：试试双击查词
打开一个英文网页（如 `en.wikipedia.org`），双击页面上的英文单词，将会弹出释义框，显示单词的音标和中文释义。⚠️注意，首次进行在线查词，用时可能稍长，约在 10～15 秒钟，请耐心等待。

## 功能说明

### 打开查词功能
点击左上角的电源开关符号，打开查词功能，再次点击关闭查词功能。

### 双击查词
操作：在任意网页上，用鼠标双击一个英文单词。
效果：
- 弹框出现，显示音标、词性、释义、例句、短语
- 单词自动加入生词本
- 弹框右上角标签显示数据来源：
  - 本地 = 来自下载的离线词典
  - 在线 = 来自有道词典（网络查询）

关闭弹框：点击页面上任意其他位置，或者滚动页面让单词离开视口。

### 划选翻译句子
操作：用鼠标按住拖动，选中一整句英文。
效果：
- 弹框出现，显示原句 + 中文翻译
- 弹框底部有「摘抄此句」按钮，点击后句子存入生词本的「摘抄」栏
注意：划选需要跨至少两个词或长度 ≥ 10 个字符才会触发。单独划一个字母不会翻译。

## 词典源设置
打开 Gloss → ⚙️ → 「词典源」，有四个选项：

本地优先：优先使用本地词典，未收录时转向在线。
在线优先：优先使用有道词典，失败时回退本地。
只查本地：用本地词典。
只查在线：只用有道词典。

推荐：日常用「在线优先」

## 生词本
点工具栏的 Gloss 图标，打开生词本。

### 三个标签页
**词库**：所有收录过的单词。
- 顶部搜索框可以搜单词、释义、笔记
- 下方筛选按钮：全部 / 待复习 / 收藏 / 已掌握
- 点击任意单词进入详情页，可以查看完整释义、添加笔记
**摘抄**：划选翻译时点过「摘抄此句」的句子。
- 每张卡片显示原句 + 译文 + 来源网址
- 点句子原文可以复制
- 右上角有复制完整内容和删除按钮
**复习**：SM-2 间隔重复复习界面。

### 单词操作
左键单击单词 → 进入详情页
右键单击单词 → 弹出菜单：
- 收藏
- 编辑笔记
- 删除
详情页可以编辑笔记、添加标签、收藏、删除。

### 底部徽章

底部的「词库」和「复习」标签上有红色数字徽章：

- 词库徽章 = 生词总数
- 复习徽章 = 今天需要复习的单词数

## 复习

### 复习流程

点底部「复习」标签，进入复习界面。
第一步：屏幕中央显示一个英文单词，不显示释义。
第二步：在脑中回忆它的意思。
第三步：
- 想不起来 → 点「显示释义」（或按空格键）
- 想跳过 → 点「下一个」（或按 → 方向键）
第四步：显示释义后，选择回忆难度：

| 按钮  | 快捷键 |
| --- | --- |
| 忘记  | 1   |
| 模糊  | 2   |
| 记得  | 3   |
| 秒答  | 4   |

根据你选的难度，算法会自动计算下次复习时间：
- 选「忘记」→ 明天再复习
- 选「记得」→ 隔几天再复习
- 连续答对 5 次 → 标记为「已掌握」，不再进入复习队列

### 快捷键
复习界面支持键盘操作：
- 空格 = 显示释义
- → = 跳过当前词
- 1 / 2 / 3 / 4 = 显示释义后评分
### 复习队列
进入复习界面时，会自动筛选出：
- 所有「新词」（第一次学习）
- 所有「待复习」的词（到了下次复习时间）
如果队列为空，会显示「暂无待复习」。

## 更新扩展

如果 GitHub 上的代码更新了，或者用户手动更改代码，需要手动同步到 Chrome。

### 从 GitHub 更新

ZIP 下载：
1. 重新去 GitHub 下载最新 ZIP
2. 解压到同一个位置（覆盖旧文件）
3. 打开 `chrome://extensions/`
4. 找到 Gloss 卡片，点右下角的 🔄 刷新按钮
5. 如果卡片上出现红色错误，点「移除」，然后重新「加载已解压的扩展程序」

git clone ：
    cd ~/你的路径/gloss
    git pull
然后前往 `chrome://extensions/` 点击刷新按钮。

### 修改代码后

自己改了代码后同步到 Chrome：
1. 打开 `chrome://extensions/`
2. 找到 Gloss 卡片，点 🔄 刷新
3. 如果修改 `content.js`：还需刷新网页才能生效（按 `Command + Shift + R`）
4. 如果修改 `manifest.json` 或 `background.js`：需要完全退出 Chrome（`Command + Q`）再重开，否则可能不生效

## 卸载
1. 打开 `chrome://extensions/`
2. 找到 Gloss 卡片
3. 点击「移除」
注意：卸载会同时删除所有生词本数据和已下载的词典，务必提前导出：
- 打开 Gloss → 设置 → 导出 JSON
- 保存文件
- 之后可通过「导入 JSON」恢复

## 常见问题

### Q：双击单词没反应？
先确认：
1. 打开 Gloss 图标，看左上角的电源按钮是不是绿色。灰色表示扩展被暂停了
2. 检查 `chrome://extensions/` 里 Gloss 是否启用，网站访问权限是否是「在所有网站上」
3. 如果刚刷新过扩展，需要刷新网页（`Command + Shift + R`）才能生效

### Q：双击后弹框一直显示「查询中」？
原因：如果选的是「只查在线」模式，可能是网络问题。
解决：
1. 打开 Gloss → 设置 → 词典源 → 改回「本地优先」
2. 确认本地词典已经下载（设置页应该显示「已安装 · XXX 词条」）

### Q：本地词典下载失败？
常见原因：
- 网络问题：CDN 拉取失败。等几分钟再试，或者换网络环境
- 磁盘空间不足：词典约 164 MB，浏览器需要额外空间做临时文件
- 浏览器缓存冲突：打开 `chrome://extensions/` → 移除 Gloss → 重装
如果反复失败，可以在 GitHub 提 Issue，附上错误信息。

### Q：为什么有的单词查不到？
原因：本地词典是从 ECDICT 精简出来的，包含约 100 万个常见词。生僻词、专有名词、人名、地名可能不包含。

解决：把词典源改成「在线优先」或「只查在线」，走有道词典的完整词库。

### Q：生词本会不会上传到云端？
不会。所有数据存在浏览器本地（`chrome.storage.local`），不上传任何服务器。换电脑或重装 Chrome 数据不会同步，需要手动导出 / 导入。

### Q：怎么备份生词本？
Gloss → 设置 → 导出 JSON。
导出的文件包含所有单词、笔记、复习进度。以后可以通过 导入 JSON 恢复。

### Q：能不能在多台电脑同步？
目前不支持。每台电脑的数据是独立的，需要用导出 / 导入手动同步。

### Q：Chrome 每次启动都提示「请停用开发者模式扩展」怎么办？
这是 Chrome 对未上架扩展的标准提示，无法关闭。
如果不想看到，唯一办法是把扩展发布到 Chrome Web Store。目前 Gloss 不上架，忽略即可——它不影响任何功能。

### Q：会不会和其他翻译扩展冲突？
可能会。如果同时装了沙拉查词、划词翻译之类的扩展，双击单词时两个弹框可能同时出现。
解决：在同一网站上只启用一个。在 `chrome://extensions/` 里可以控制每个扩展的网站访问权限。

### Q：怎么暂停 Gloss？
点工具栏图标 → 左上角电源按钮，点一下变成灰色。当前网站就不再触发查词。
如果需要针对特定网站禁用，去 设置 → 当前网站 → 点「加入黑名单」。

### Q：支持哪些浏览器？
Chrome、Edge、Brave、Arc、Opera 等所有 Chromium 内核浏览器。
不支持 Firefox 和 Safari。

## 隐私
Gloss 不收集任何用户数据。

具体来说：
- 生词本、摘抄、笔记、复习进度：全部存储在浏览器本地的 `chrome.storage.local`，不上传
- 离线词典：存储在浏览器的 IndexedDB，不上传
- 只有查词 / 翻译时，会向有道词典 API 发送单词或句子文本，不发送任何用户身份信息
- 没有第三方分析、没有追踪、没有广告

## 技术信息
- 基于 Chrome Extension Manifest V3
- 词典数据：ECDICT（开源英汉词典）
- 在线查词：有道词典公开接口
- 备用在线词典：Free Dictionary API
- 复习算法：SM-2（Anki 同款）
- 音频播放：Offscreen API
代码结构：
    background.js    后台：查词、翻译、下载词典、音频播放
    content.js       页面注入：双击、划选、弹框
    popup.html/js    生词本界面
    offscreen.html   音频播放沙盒
    dict-parts/      打包后的离线词典（10 个分片，共 164 MB）
    build-dict.js    把 dict/ 原始分片打包成 dict-parts/ 的脚本

### 打包脚本用法
如果你需要修改词典内容：
    # 1. 把 ECDICT 的原始分片放到 dict/ 目录下
    # 2. 运行打包脚本
    node build-dict.js
    # 3. 生成的 dict-parts/ 就是扩展实际使用的词典
