# Gloss

一个 Chrome 扩展：双击网页上的英文单词，弹出释义，自动记录到生词本。

也支持划选句子翻译、按 SM-2 算法复习。

---

## 功能

- 双击英文单词查词
- 划选整句翻译，可摘抄到生词本
- 生词本支持收藏、笔记、搜索
- SM-2 间隔重复复习
- 本地词典（ECDICT）+ 在线词典（有道）双词典源，可切换
- 音标、发音、例句、短语
- 弹窗根据单词位置自适应左右上下，跟随滚动

数据全部存在本地，不上传服务器。
