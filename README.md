# Gloss

Chrome 扩展。双击网页上的英文单词，弹出中文释义并自动记录到生词本，支持划选句子翻译和 SM-2 间隔复习。

## 安装

Gloss 未上架 Chrome Web Store，需以开发者模式手动加载。整个过程约 1 分钟。

### 环境要求

Chrome 或任何基于 Chromium 的浏览器（Edge、Brave、Arc、Opera 等）。不支持 Firefox 和 Safari。

### 第一步：下载代码

**方式 A**：在 GitHub 仓库页面点击右上角 `<> Code` → `Download ZIP`，下载 `gloss-main.zip`。

**方式 B**：已安装 git 时，使用命令行：
```
git clone https://github.com/Esslooooo/gloss.git
```

### 第二步：解压

将 ZIP 解压到一个长期保留的位置（例如 `~/Documents/Gloss` 或 `D:/Gloss`）。

解压后的文件夹不得删除或移动。Chrome 每次启动都会从该路径读取扩展代码。

正确的文件夹结构：
```
Gloss/
├── manifest.json
├── background.js
├── content.js
├── popup.html
├── assets/
│ └── icon/
├── dict-parts/
└── ...
```


打开文件夹时，应能直接看到 `manifest.json`。如果看到的是内嵌的一层 `gloss-main` 文件夹，说明多了一层目录，Chrome 加载时会因找不到清单文件而失败。

### 第三步：加载到 Chrome

1. 地址栏输入 `chrome://extensions/` 并回车
2. 打开页面右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择第二步解压出的文件夹
5. 加载完成后，扩展卡片会出现在页面上，名称为 **Gloss**

### 第四步：固定到工具栏

Chrome 默认将新扩展收纳在「扩展程序」菜单中。

1. 点击地址栏右侧的拼图图标
2. 找到 **Gloss**
3. 点击右侧的图钉图标

### 注意事项

Chrome 会在启动时提示「请停用以开发者模式运行的扩展程序」。这是对未上架扩展的标准提示，不影响功能，可直接忽略。

## 首次使用

### 下载本地词典

打开 Gloss → 点击右上角齿轮图标 → 找到「本地词典」区域 → 点击「下载本地词典」。

将从 CDN 下载约 100 万条词条，耗时 1~3 分钟，具体取决于网络速度。下载完成后状态显示为「已安装 · XXXXXXX 词条」，此后即使离线也可查词。

### 测试查词

打开任意英文网页（例如 `en.wikipedia.org`），双击页面上的英文单词，会弹出释义框，显示音标和中文释义。

首次在线查词可能需要 10~15 秒，请耐心等待。

## 功能说明

### 启用与暂停

点击标题栏左上角的电源按钮，可开启或关闭查词功能。按钮为绿色表示已启用，灰色表示已暂停。

### 双击查词

在任意网页上双击英文单词，弹出释义框，显示音标、词性、释义、例句和短语。单词会自动加入生词本。

弹框右上角的标签显示数据来源：

- **本地**：来自下载的离线词典
- **在线**：来自有道词典

关闭弹框的方式：点击页面其他位置，或将页面滚动至单词离开视口。

### 划选翻译

用鼠标拖动选中一整句英文，弹出翻译框，显示原句和中文翻译。点击框底的「摘抄此句」按钮，句子会存入生词本的「摘抄」栏。

划选需至少跨越两个单词，或选中长度 ≥ 10 个字符，才会触发翻译。

## 词典源

打开 Gloss → 齿轮图标 → 「词典源」，共四个选项：

| 选项 | 说明 |
|------|------|
| 本地优先 | 优先使用本地词典，未收录时转向在线 |
| 在线优先 | 优先使用有道词典，失败时回退本地 |
| 只查本地 | 仅使用本地词典 |
| 只查在线 | 仅使用有道词典 |

默认推荐「在线优先」，兼顾释义丰富度和响应速度。

## 生词本

点击工具栏 Gloss 图标，打开生词本。共三个标签页。

### 词库

所有收录过的单词。

- 顶部搜索框支持搜索单词、释义和笔记
- 筛选按钮：全部 / 待复习 / 收藏 / 已掌握
- 左键点击单词进入详情页，可查看完整释义、添加笔记
- 右键点击单词弹出菜单，支持收藏、编辑笔记、删除

### 摘抄

划选翻译时点击过「摘抄此句」的句子。

- 每张卡片显示原句、译文和来源网址
- 点击句子原文可复制
- 右上角提供复制完整内容、导出和删除按钮
- 支持导出为 Markdown（.md）或纯文本（.txt）文件

### 复习

SM-2 间隔重复复习界面，详见下一节。

### 底部徽章

底部导航的「词库」和「复习」标签上有红色数字徽章：

- 词库徽章：生词总数
- 复习徽章：今日待复习单词数

## 复习

### 流程

1. 点击底部「复习」标签，进入复习界面
2. 屏幕中央显示一个英文单词，不显示释义
3. 在脑中回忆其含义
4. 有两种操作：
   - 想不起来 → 点击「显示释义」或按空格键
   - 想跳过 → 点击「下一个」或按 → 方向键
5. 显示释义后，根据回忆难度选择评分：

| 按钮 | 快捷键 | 含义 |
|------|-------|------|
| 忘了 | 1 | 完全不记得 |
| 模糊 | 2 | 有印象但不清晰 |
| 记得 | 3 | 基本记得 |
| 秒答 | 4 | 完全掌握 |

SM-2 算法根据评分自动计算下次复习时间：

- 选「忘了」→ 明天再复习
- 选「记得」→ 间隔数天后复习
- 连续答对 5 次 → 标记为「已掌握」，不再进入复习队列

### 复习队列

进入复习界面时自动筛选：

- 所有「新词」（第一次学习）
- 所有「待复习」的词（已到复习时间）

队列为空时显示「暂无待复习」。

## 更新

### 从 GitHub 更新

**ZIP 下载**：

1. 重新下载最新 ZIP
2. 解压到同一位置并覆盖旧文件
3. 打开 `chrome://extensions/`
4. 找到 Gloss 卡片，点击刷新按钮
5. 若卡片出现红色错误，先移除再重新加载

**git clone**：
```
cd ~/你的路径/Gloss
git pull
```

然后前往 `chrome://extensions/` 点击刷新按钮。

### 修改代码后

1. 打开 `chrome://extensions/`
2. 找到 Gloss 卡片，点击刷新
3. 修改了 `content.js` / `content.css`：需刷新测试网页（`Command + Shift + R`）
4. 修改了 `manifest.json` / `background.js`：需完全退出 Chrome（`Command + Q`）后重开

## 卸载

1. 打开 `chrome://extensions/`
2. 找到 Gloss 卡片
3. 点击「移除」

**注意**：卸载会同时删除所有生词本数据和已下载的词典。如需保留，请提前导出：

- 打开 Gloss → 设置 → 导出 JSON
- 保存文件后，可在重装后通过「导入 JSON」恢复

## 常见问题

### 双击单词无反应

依次检查：

1. Gloss 图标左上角电源按钮是否为绿色。灰色表示已暂停
2. `chrome://extensions/` 中 Gloss 是否启用，网站访问权限是否设为「在所有网站上」
3. 若刚刷新过扩展，需刷新网页（`Command + Shift + R`）后才生效

### 弹框一直显示「查询中」

原因：若词典源设为「只查在线」且网络不稳定，可能出现此问题。

解决：

1. 打开 Gloss → 设置 → 词典源 → 改为「本地优先」
2. 确认本地词典已下载（设置页显示「已安装 · XXX 词条」）

### 本地词典下载失败

常见原因：

- 网络问题：CDN 拉取失败，可稍后重试或更换网络环境
- 磁盘空间不足：词典约 164 MB，浏览器还需额外空间做临时文件
- 缓存冲突：`chrome://extensions/` → 移除 Gloss → 重装

反复失败时，可在 GitHub 提交 Issue 并附上错误信息。

### 部分单词查不到

本地词典基于 ECDICT 精简，包含约 100 万常见词条。生僻词、专有名词、人名、地名可能未收录。

解决：将词典源改为「在线优先」或「只查在线」。

### 数据是否会上传云端

不会。所有数据存储在浏览器本地（`chrome.storage.local` 和 IndexedDB），不经过任何服务器。

跨设备同步目前不支持，需通过导出 / 导入手动迁移。

### 如何备份生词本

Gloss → 设置 → 导出 JSON。

导出文件包含所有单词、笔记和复习进度。重装后可通过「导入 JSON」恢复。

### Chrome 提示「请停用开发者模式扩展」

这是 Chrome 对未上架应用商店的扩展的固定提示，无法关闭。忽略即可，不影响使用。

### 是否与其他翻译扩展冲突

可能。同时安装沙拉查词、划词翻译等扩展时，双击单词可能触发多个弹框。

解决：在 `chrome://extensions/` 中控制各扩展的网站访问权限，同一网站仅启用一个。

### 如何暂停 Gloss

点击工具栏图标 → 左上角电源按钮，切换为灰色即暂停。

针对特定网站禁用：设置 → 当前网站 → 点击「加入黑名单」。

## 隐私

Gloss 不收集任何用户数据。

具体而言：

- 生词本、摘抄、笔记、复习进度：存储在浏览器本地 `chrome.storage.local`
- 离线词典：存储在浏览器 IndexedDB
- 仅在查词 / 翻译时向有道词典 API 发送单词或句子文本，不发送任何用户身份信息
- 无第三方分析、无追踪、无广告

## 技术信息

- Chrome Extension Manifest V3
- 词典数据：ECDICT（开源英汉词典）
- 在线查词：有道词典公开接口
- 备用在线词典：Free Dictionary API
- 复习算法：SM-2
- 音频播放：Offscreen API

### 代码结构
```
background.js 后台：查词、翻译、词典下载、音频播放
content.js 页面注入：双击、划选、弹框
popup.html/js 生词本界面
popup.css 生词本样式
content.css 网页弹框样式
offscreen.html 音频播放沙盒
offscreen.js
assets/icon/ 扩展图标
dict-parts/ 打包后的离线词典（10 个分片，共 164 MB）
dict/ ECDICT 原始分片（开发用，不打包进扩展）
build-dict.js 把 dict/ 打包成 dict-parts/ 的构建脚本
```


### 构建离线词典

如需修改词典内容：

1. 将 ECDICT 原始分片放入 `dict/`
2. 执行构建脚本：
```
node build-dict.js
```


3. 生成的 `dict-parts/` 即扩展实际使用的词典
